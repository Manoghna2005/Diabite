# Reproducibility notes

1. Install Node.js.
2. Open a terminal in `Source Codes/`.
3. Run `npm install`.
4. Copy `.env.example` to `.env.local` and set `GEMINI_API_KEY` only if using the Gemini feature. Do not commit real API keys.
5. Run `npm run dev` to start the local app.

The app uses bundled sample data under `Source Codes/src/data/`. The AI Studio preview link is recorded in `DemoLink.txt`; access may require Google AI Studio permission.
